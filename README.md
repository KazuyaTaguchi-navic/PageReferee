# ページレフェリー

「通販する蔵」の商品登録ページを、管理表・車種別タグ表と突き合わせてその場でチェックするChrome拡張機能です。

これまでCSVをダウンロードしてGASの管理表と見比べていた確認作業を、通販する蔵のページを開いたままボタン1つで行えるようにします。自社品番をキーに管理表・車種別タグ表と照合し、コピー元品番の消し忘れ・楽天/ヤフーURLの取り違え・価格や送料の入力ミス・車種別タグの入れ忘れなどを検出して、レッドカード（重大なミス）／イエローカード（軽微なミス）の件数で表示します。カード一覧をクリックすると該当箇所まで自動でスクロールし、色付きのハイライトが表示されます。

このほか、ページ作成ルールブックをもとにAIが質問に答える「💬 質問する」チャットボット、確認結果（レッド/イエロー件数・スクリーンショット）をスプレッドシートへ自動記録する実績記録機能も搭載しています（どちらも任意設定・未設定のままでも基本機能は問題なく使えます）。

## 導入方法（誰でもできます）

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、この `PageReferee` フォルダを選択する
4. ツールバーに🚩アイコンが表示されれば導入完了です

## 初回セットアップ

🚩アイコンを右クリック→「オプション」（または拡張機能ページの「詳細」→「拡張機能のオプション」）を開くと、①〜⑩の設定項目があります。①②は必須、③〜⑩は任意（未設定でも基本のチェック機能は使えます）です。

1. **① 管理表ファイル（毎月更新）**: いつも使っている管理表（.xlsx）をダウンロードして選択する
   - 「管理表」シートは初回、自動でチェックが入ります。他のメーカー別シートも必要に応じてチェックを入れてください
   - 列の対応付け（自社品番・品番・SKU・定価税抜・定価税込・売価税抜・売価税込・原価・シリーズ・コピー元）を確認する。よくある列名は自動で候補を選んでくれますが、税抜/税込を取り違えていないか必ず確認してから「商品シート設定を保存」を押してください
   - 依頼シート・基準・リストなど商品データではないシートにはチェックを入れないでください
2. **② 車種別タグ表ファイル**: 車種別タグの一覧表（.xlsx）を選択し、`★リスト`シート（自社品番→タグの対応）・`★タグ一覧`シート（車種名→タグの辞書、タグ候補の自動提示用）の列を確認して保存する
3. これで基本のチェック機能は準備完了です。あとは通販する蔵の商品編集ページで🚩アイコンをクリックしてください
4. （任意）③〜⑩の設定内容は下記「何を設定できるか（③〜⑩）」を参照してください

## 使い方

1. 通販する蔵で商品編集ページを開く
2. ツールバーの🚩アイコンをクリックする → 右上に確認パネルが表示される（⑥自動起動設定をしている場合は、対象URLを開くだけで自動的に表示されます）
3. 「確認する」を押す → 自社品番をもとに管理表・タグ表と照合し、🔴レッドカード／🟡イエローカードの件数が表示される（⑧実績記録を設定している場合は、この時点で結果とスクリーンショットが自動でスプレッドシートに記録されます）
4. カードやリストの各項目をクリックすると、該当箇所まで自動スクロールしてハイライト表示される（項目グループが折りたたまれている場合は自動で開きます）
5. 「ページ: ○○ / 管理表: ××」のように不一致が表示された項目には📋ボタンが付いており、押すと管理表側の値をクリップボードにコピーできます（ページ側の入力欄に貼り付けるだけで直せます）
6. パネルはドラッグで移動、「▸／▾」で最小化・展開の切り替え、「✕」で閉じられます
7. ⑦チャットボット設定をしている場合、パネル下部の「💬 質問する」欄からルールブックの内容についてAIに質問できます。「▸」で開閉、右上の📋「やりとりをコピー」ボタンでそれまでの質疑応答をまとめてコピーでき、チャットワーク等で担当者に相談する際にそのまま貼り付けられます
8. ⑨登録ボタンのロックを有効にしている場合、レッドカードが0件になっていない（または一度も「確認する」を実行していない）状態で通販する蔵の「登録」ボタンを押すと、理由が表示されてブロックされます（イエローカードのみが残っている場合は登録できます）

### 月次更新時（管理表のURLが毎月変わる場合）

管理表を最新のものに差し替えたいときは、設定画面の「① 管理表ファイル」で新しいファイルを選び直すだけです。列マッピングは前回の設定が引き継がれます（シート名が同じであれば）。

### ページ側の項目を追加・修正したいとき

通販する蔵の実ページで確認済みの主要項目（自社品番・価格・送料・楽天/ヤフー説明文・Amazon項目・商品タグ・SKU情報 等）はあらかじめ設定済みです。それ以外の項目を追加したい、またはページの仕様変更で読み取れなくなった場合は、対象のページを開いて🚩ボタンでパネルを表示した状態のまま、設定画面の「③ ページ側の項目マッピング」で対象項目の「指定する」を押してください。自動でそのページに切り替わるので、該当する入力欄をクリックすると割り当てられます（Escでキャンセルできます）。

### チームで設定を共有する

設定画面の「⑩ 設定のエクスポート・インポート」で、列マッピング・項目マッピング・重大度設定・モールURLのひな形・Gemini APIキー・実績記録用WebアプリURLをJSONとして書き出せます。最初の1人が設定を済ませたら、そのJSONを他の担当者に配って「インポート」してもらうだけで同じ設定（チャットボット・実績記録を含む）がすぐ使えます（管理表・タグ表・ルールブックのファイル自体は含まれないので、各自でファイルを選択・設定する必要があります）。⑥自動起動設定・⑨登録ボタンのロックは会社ごとに運用が異なるため、このJSONには含まれません（必要な人が各自で設定します）。

⚠️ このJSONにはGemini APIキーがそのまま含まれます。取り扱いには注意し、渡す相手を限定してください。また、インポートしただけでは実績記録のスクリーンショット権限は有効になりません。インポート後に「⑧ 実績記録設定」の保存ボタンを押し直し、表示される権限ダイアログを許可してください（ブラウザの権限許可は本人の操作が必須なため）。

## 何を設定できるか（③〜⑩、任意設定）

- **③ ページ側の項目マッピング**: 通販する蔵側の仕様変更等でチェック項目が読み取れなくなったときに、実ページをクリックして読み取り位置を指定し直す機能
- **④ 重大度設定**: 通販する蔵の全項目について、不一致時にレッドカード／イエローカード／なし、のどれにするかを個別に変更できる。先頭の「AIチェック（する蔵の項目ではありません）」区分に「誤字脱字チェック」があり、ここをレッド/イエローに変更すると⑦のAPIキー設定時に「確認する」のたびにAIが商品名・説明文の誤字脱字をチェックするようになる（初期値は「なし」＝オフ）
- **⑤ モールURLのひな形**: モール取り違えチェック（ヤフー側に楽天URL・楽天側にヤフーURLが混ざっていないか）で不一致が見つかったときに、📋ボタンでコピーできる正しいURLのひな形
- **⑥ 自動起動設定**: 指定したURLで始まるページを開くと🚩ボタンを押さなくても自動的にパネルが（最小化された状態で）表示されるようにする設定。エクスポートJSONには含まれないため、必要な人は各自で設定する
- **⑦ チャットボット設定**: Gemini APIキーと、ページ作成ルールブックのスプレッドシートURLを設定すると、パネルの「💬 質問する」欄が使えるようになる。ルールブックに記載がない質問は、内容に応じて「メーカーページを確認してください」の案内や、カー用品ECの一般的な知識に基づく回答（「社内ルールではなく一般的な知識に基づく回答です」と明記）を返す。Gemini API無料枠のレート制限に達した場合は日本語のエラーメッセージが表示される
- **⑧ 実績記録設定**: 「確認する」完了のたびに、自社品番・日時・レッド/イエロー件数・パネル部分のスクリーンショットを、指定したGoogle Apps Script Webアプリ経由でスプレッドシートへ自動記録する。設定手順（GAS側のコード含む）は設定画面内に記載
- **⑨ 登録ボタンのロック**: ONにすると、レッドカードが0件になる（かつ「確認する」実行後に内容を変更していない）まで、通販する蔵の「登録」ボタンを押せなくする（イエローカードのみが残っている場合は登録できる）。管理表に自社品番が見つからない場合や、一度も「確認する」を実行していない場合もブロック対象。この機能はページレフェリーがそのページに読み込まれていて初めて働くため、🚩ボタンの押し忘れにも対応したい場合は⑥自動起動設定とあわせて使う。初期値OFF、会社ごとに個別設定（エクスポートJSONには含まれない）
- **⑩ 設定のエクスポート・インポート**: 上記の設定（⑥⑨を除く）をJSONで書き出し・読み込みする機能（詳細は上記「チームで設定を共有する」を参照）

## 何をチェックしているか

「重要項目.txt」の指定に基づき、管理表の列と通販する蔵の各項目を以下のように対応付けてチェックしています。

1. **自社品番の一致**（管理表K列）: 基本情報の自社品番・楽天の商品管理番号(商品URL)・商品番号・ヤフーの商品コードが一致しているか（自社品番の表記ルール自体が正しいかの形式チェックも含む）
2. **品番の一致**（管理表M列）: 基本情報のメーカー品番・メーカー品名が一致しているか（商品名・商品名略称に古い品番が残っていないかは3のコピー元チェックで検出）
3. **コピー元の残存チェック**: コピー元商品からコピーして作成した場合に、商品名・商品名略称・各説明文にコピー元の品番、または同じメーカーの他商品の品番がそのまま残っていないかを確認
4. **SKU/JANの一致**（管理表L列）: SKU情報のSKU・正規JAN、ヤフーのJANコード、楽天のカタログIDが一致しているか。SKUコードの入力漏れ・桁数・表示順の重複もあわせて確認
5. **金額の一致**（管理表U〜Y列、超重要）: 基本情報のメーカー希望小売価格＝定価(税抜)、ヤフーの定価＝定価(税込)、楽天の販売価格＝売価(税抜)、ヤフーの通常販売価格＝売価(税込)、基本情報の原価＝原価。管理表側が空欄/0の場合（オープン価格）は、ページ側も空欄であればチェック対象外とする
6. **送料の一致**: 個別送料・送料特別加算金額を管理表の送料・特別加算金と比較。あわせて売価税込3980円を境に、楽天の送料区分（送料込/送料別）とYahoo!の重量区分・送料無料設定が正しく設定されているかを確認
7. **シリーズ・車種名整合性（参考）**: 商品名に管理表のシリーズ名・車種名が含まれているかをやわらかくチェック（イエロー）。あわせて商品名からサイトカテゴリの選択ミス（商品タイプとサイトカテゴリの不整合）がないかを確認
8. **モール取り違えチェック**: ヤフー側の説明文に楽天のURLが、楽天側の説明文にヤフーのURLが混ざっていないかを確認。見つかった場合は📋ボタンで正しいモールのURL（設定画面「⑤ モールURLのひな形」で設定）をコピーできます
9. **車種別タグチェック**: 自社品番から車種別タグ表を参照し、必要なタグが揃っているか・不要なタグが付いていないかを確認
10. **タグ候補提示**（APIなし）: 商品名・説明文に含まれる車種名から、まだ付いていないタグの候補をキーワード一致で提示（要確認）
11. **PC版／スマホ版の内容不一致チェック**: 楽天のPC用・モバイル用・スマホ用商品説明文の内容が大きく食い違っていないかを確認
12. **Amazon項目のチェック**: 楽天SKUのASINが登録されている場合は販売価格（税込）等が管理表と一致しているかを確認し、ASINが未登録の場合は逆に発送日数・配送パターン・各種価格・セール期間・ギフト・販売形態が初期値（未入力）のままになっているかをすべてレッドカードで確認します（Amazon出品時に別途入力するため、未登録段階では入力不要）
13. **セット整合性**: SKU行数・SKU側品番と管理表のセット構成の一致確認
14. **新規登録時の固定ルール**（「【新規ページ確認】.txt」に基づく）:
    - 楽天の注文ボタンが「ボタンをつけない」、ヤフーのページ公開が「非公開」になっているか
    - サイト掲載フラグが楽天・Yahoo!のみチェック（Amazon・ヤフオク・新ヤフオクは未チェック）になっているか
    - 楽天のサイトカテゴリ1・ジャンルID、Yahoo!のプロダクトカテゴリが設定されているか
    - 楽天のポイント変倍率が「個別設定しない」になっているか
    - Yahoo!の商品別ポイント倍率が「一律に設定」→「商品別倍率指定なし」になっているか
    - Amazonの「ポイント」が空欄になっているか
    - 楽天に動画(HTML)が設定されている場合、Yahoo!側にもアップロードが必要な旨をリマインド表示
15. **AI誤字脱字チェック**（任意・設定画面④で個別にオン/オフ）: 商品名・各モールの商品説明文をGemini APIでチェックし、誤字脱字の疑いがあれば指摘します。する蔵側の項目チェックとは性質が異なるため、初期値はオフ、設定画面でも専用の区分に分けて表示しています

レッド／イエローどちらのカードにするかは設定画面の「④ 重大度設定」で自由に変更できます（初期値は「20260820_通販する蔵_入力項目.xlsx」のSheet1（赤字＝レッドカード・黒字＝イエローカード）とシート1の項目一覧に準拠）。

### 自動チェックの対象外（目視確認が必要）

商品説明文の内容そのものの適合性・キャッチコピーの妥当性、画像・動画の中身（例: 楽天の画像19〜20にキャンペーン画像が残っていないか）など、文章や画像の「正しさ」を判断する項目は自動チェックの対象外です（誤字脱字のみ任意でAIチェック可能）。特に画像ファイルは仕様上ブラウザから中身を読み取れないため、これらは引き続き目視で確認してください。

## フォルダ構成

```
PageReferee/
├─ manifest.json         拡張機能の設定（Manifest V3）
├─ background.js         ツールバーボタンのクリック・自動起動でページに確認パネルを注入する／
│                        Gemini APIへの問い合わせ、実績記録Webアプリへの送信、スクリーンショットの
│                        撮影・切り抜きなど、外部通信が必要な処理をまとめて行う
├─ content/
│  ├─ content.js         確認パネル本体（通販する蔵のページ上で動作。チャットボット・実績記録の
│  │                     呼び出しも含む）
│  ├─ content.css
│  └─ auto-flag.js       自動起動時のみ読み込まれる目印用スクリプト（パネルを最小化表示で開くために使用）
├─ options/               設定画面（管理表・タグ表の読み込み、列/項目マッピング、重大度設定、
│                        チャットボット・実績記録・自動起動・エクスポート/インポート）
├─ lib/
│  ├─ xlsx.full.min.js   xlsx読み込み用ライブラリ（SheetJS、オフライン同梱）
│  ├─ workbook.js         xlsxのパース処理
│  ├─ rulebook.js         ルールブックスプレッドシートの取得・パース処理
│  ├─ rules.js            比較ルールエンジン
│  └─ storage.js          設定の保存・既定値・エクスポート/インポート
└─ icons/                 拡張機能アイコン
```

## 外部通信について

管理表・車種別タグ表は、ローカルで選択したファイルをその場で読み込むだけで外部通信は行いません。

一方、以下の機能は任意設定であり、設定した場合のみ次の外部通信が発生します（未設定であればどちらも通信は発生しません）。

- **⑦ チャットボット**: 質問内容をGemini API（`generativelanguage.googleapis.com`）に送信して回答を取得します。また、ルールブックのスプレッドシート（`docs.google.com`、リンクを知っている全員に公開設定したもの）を都度取得します
- **⑧ 実績記録**: 「確認する」完了時に、自社品番・日時・件数・スクリーンショットを設定したGoogle Apps ScriptのWebアプリ（`script.google.com`）に送信します

## 注意事項

- 本ツールは入力ミスの「気づき」を助けるものです。最終的な公開前の確認は引き続き目視でも行ってください
- 通販する蔵側の画面仕様が変わった場合、既定の項目マッピングが効かなくなることがあります。その場合は設定画面の「③ ページ側の項目マッピング」で指定し直してください
- `chrome://extensions` で拡張機能を再読み込みした直後は、すでに開いていた通販する蔵のタブに残っているパネルが古い状態のままになり、ボタンを押すと「Extension context invalidated」というエラーが出ることがあります。その場合はページを再読み込み（F5）してから、もう一度🚩ボタンを押してください
- チャットボット・AI誤字脱字チェックはGemini APIの無料枠を利用しているため、短時間に多用するとレート制限（利用回数上限）に達し、日本語のエラーメッセージが表示されることがあります。その場合はしばらく時間をおいてから再度お試しください
